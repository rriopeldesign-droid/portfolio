The Problem

One email, four tools

Every campaign took the same route. Design it in Figma, export the HTML with a plugin, hand it off to Braze, then fix everything that broke on the way. Four tools and three hand-offs, for every single email.

So I built a tool that replaces the whole chain. It’s a small Next.js app that does one job: let anyone on marketing build an on-brand, production-ready email without design or engineering support.

Design Decision

Blocks, not a blank canvas

A free-form editor would have moved the problem, not solved it. Anyone could drag a box anywhere, and every email would need a designer to check it again.

So the builder has no blank canvas. Every email is a stack of blocks, and every block is already built from RVezy’s email styles: the type, the spacing, the blue buttons, the light and dark palettes. People choose blocks and write the words, and the design comes with the block.

The hard parts of HTML email live inside the blocks too, so nobody has to think about them: table layouts, Outlook fallbacks, phone sizes and tracking links.

What the builder handles, so nobody has to

  • Light and dark

    Every block has a light and a dark palette. You build in one, and copy the HTML for that one.

  • Desktop and phone

    Preview at the full 660 px or at phone width. The exported HTML carries its own styles for small screens.

  • Email-safe HTML

    Table layouts and Outlook fallbacks, the markup inboxes still need, written by the tool instead of by hand.

  • Personalization

    Braze Liquid tags with fallbacks. A first name falls back to “Explorer”, and the preview shows the fallback.

  • Tracking

    A UTM builder adds source, medium, campaign and content to every button link, so no campaign goes out untracked.

  • AI copy assist

    Name a field, describe what you want, and the builder drafts the copy, with the subject line as context.
